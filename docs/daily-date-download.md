# Daily date menu and download

Date header opens a list of dates for the selected month. Choosing a date via dropdown or row sets the single-day summary and closes both the dropdown and Daily Records card.

A line-style download icon sits beside the Daily Records title. Its independent from/to date form defaults to the current summary range. Download triggers an authenticated Excel response and closes the range form; it does not change the displayed summary or close the card.

Workbook includes daily cash purchases, Employee Expense, voided cash purchases and totals, plus category/Other-description amounts for the selected period. Same-day and cross-month ranges supported, including zero days. Dates validated; existing office access enforced. No credit, Admin Expense or topups. Existing top-toolbar ledger export is unchanged.
